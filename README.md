# مباريات الدوري الإنجليزي بصيغة JSON

مشروع ينشئ `matches.json` باللغة العربية باستخدام مصدر بيانات مباريات خارجي، ويُحدّث الملف تلقائيًا عبر GitHub Actions كل 15 دقيقة.

## الملفات
- `update.py`: جلب المباريات ومعالجتها وفرزها.
- `matches.json`: ملف JSON الناتج.
- `.github/workflows/update.yml`: تشغيل التحديث تلقائيًا.

## التثبيت
1. أنشئ مستودع GitHub باسم `premier-league-json`.
2. ارفع كل ملفات هذا المشروع إلى الفرع `main` مع الحفاظ على مسار `.github/workflows/update.yml`.
3. افتح تبويب **Actions** وفعّل GitHub Actions إذا طلب منك ذلك.
4. شغّل سير العمل **تحديث مباريات الدوري الإنجليزي** يدويًا عبر **Run workflow**.
5. راجع سجل التشغيل. إذا فشل مصدر البيانات أو تغيّرت بنية الاستجابة، لن يستبدل البرنامج الملف ببيانات وهمية.
6. من **Settings → Pages** اختر النشر من الفرع `main` والمجلد `/ (root)` ثم احفظ.

## رابط JSON
بعد تفعيل GitHub Pages سيكون الرابط:
`https://USERNAME.github.io/premier-league-json/matches.json`

استبدل `USERNAME` باسم حساب GitHub.

## ملاحظات
- التحديث مجدول كل 15 دقيقة، لكنه قد يتأخر حسب ضغط GitHub Actions.
- الوقت المتبقي داخل الملف يعكس آخر تشغيل ناجح؛ اطلب JSON مجددًا ولا تتوقع أن يتغير الحقل داخل نسخة ثابتة من الملف تلقائيًا.
- تفاصيل الملعب ومسجلي الأهداف تعتمد على الحقول التي يوفّرها المصدر للمباراة؛ قد تكون `null` أو قائمة فارغة إذا لم تكن متاحة.
- إذا تغير شكل رد API، راجع سجل Actions وعدّل `list_from_response` أو `normalize`.
- هذا المشروع لا يضع بيانات مباريات تخمينية على أنها حقيقية.
